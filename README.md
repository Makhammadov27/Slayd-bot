# SLAYD Bot

AI yordamida taqdimot (.pptx) yaratadigan Telegram bot (Node.js, grammY, Gemini).

## Ishga tushirish
```bash
npm install
cp .env.example .env   # BOT_TOKEN, GEMINI_API_KEY, ADMIN_IDS ni to'ldiring
npm start
```

Node.js 22.13+ kerak. Doimiy ishlatish uchun PM2: `pm2 start ecosystem.config.cjs`.
